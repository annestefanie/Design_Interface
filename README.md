# Interface Design Portfolio

A compilation of my university projects on Human-Computer Interaction (HCI), usability and interface design. This repository brings together three previously separate projects into a single place, preserving their original commit history.

## Projects

### 📁 [Human-Computer_Interaction_Interface](./Human-Computer_Interaction_Interface)
Project developed for the Human-Computer Interaction course, exploring how people interact with digital interfaces.

### 📁 [10_Heuristicas_de_Usabilidade](./10_Heuristicas_de_Usabilidade)
A study of Nielsen's 10 Usability Heuristics, the widely used principles for evaluating and improving the usability of user interfaces.

### 📁 [Hub_Conceitos_Design_Interface](./Hub_Conceitos_Design_Interface)
A webpage created for the Interface Development course. It compiles information on the course's most well-known and important concepts, and serves as a space to practice the topics learned along the way.

## How to Use

Clone the repository:

```bash
git clone https://github.com/annestefanie/Portfolio_Design_Interface.git
```

Then open the folder of the project you want to explore. For the web-based projects, open the `index.html` file in your browser.
