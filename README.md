> Projeto web interativo e responsivo focado no ensino dos fundamentos, evolução e aplicação prática de Interação Humano-Computador (IHC). Desenvolvido como requisito prático para a disciplina de **Desenvolvimento de Interfaces**.

---

## Sobre o Projeto

Este projeto consiste em uma aplicação web concebida para servir como um guia acessível e estruturado sobre **Interação Humano-Computador (IHC)**. O objetivo principal foi aplicar na prática os conceitos de **design de interface, usabilidade e acessibilidade** enquanto se constrói uma plataforma educativa sobre o próprio tema.

### 💡 Conteúdo Abordado
- **Conceito & Fundamentos:** O que é IHC, seus objetivos centrais e impacto na experiência do usuário (UX).
- **Características & Princípios:** Diretrizes de usabilidade, heurísticas e ergonomia de software.
- **Evolução Histórica:** Linha do tempo das interfaces (de linhas de comando às interfaces naturais/NUI).
- **Relatório Prático:** Documentação da atividade acadêmica realizada.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias fundamentais da web, priorizando código limpo, semântica e performance sem dependência de bibliotecas externas.

- **HTML5;**
- **CSS3;**
- **JavaScript.**
