Resumo

Os conceitos de UX e UI design aplicados para o desenvolvimento de interfaces buscam fidelizar o cliente por meio de uma experiência melhor para o usuário ao interagir com um produto. Eles buscam estudar o comportamento do usuário por meio de pesquisas e empatia, se preocupando e facilitando a vida do seu cliente. O profissional vai buscar entender o objetivo principal da empresa e direcionar seu design e funcionamento para converter e garantir que os processos até o objetivo sejam alcançados.

Definição

User Experience

UX e UI são acrônimos amplamentes conhecidos no design que simbolizam user experience (experiência do usuário) e user interface (interface do usuário). O conceito de UX é utilizado para falar da relação de um usuário com um produto, essa relação pode ter sido boa ou ruim. Um exemplo de experiência de usuário é um pacotinho de ketchup, um cliente pode ter tido dificuldade para abrir e se sujado dependendo da embalagem, mas em outras com o rótulo "abre fácil" ter tido facilidade. Já o conceito de UI faz parte do UX, vai ser onde o usuário vai interagir com o produto, parte do software. Nessa sistuação, os conceitos de experiência vão ser aplicados a interface, para garantir que ela tenha uma boa usabilidade e garanta uma fidelidade do cliente.


User Interface

Afinal, onde o conceito de UI é aplicado? Ele é aplicado em aplicativos, sites, sistemas embarcados dispositivos inteligentes e softwares. É responsável por projetar sua aparência visual, a disposição dos elementos e a interação do usuário com a interface. Não busca apenas melhorar a parte estética, mas também a experiência do usuário, por meio de composição visual, elementos, íncones, animações, feedback visual, entre outros.
